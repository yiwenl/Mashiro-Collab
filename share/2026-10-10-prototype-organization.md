# 複数の案を試せるように、フォルダーと作業ガイドを整理しました

- 日付: 2026-10-10
- 対象: プロジェクト全体、circles08

## 何を変えたか

今ある作品を `prototypes/circles08/` にまとめました。今後は別の方向のプロトタイプを隣のフォルダーへ追加し、それぞれを独立して試せます。ルートの [README](../README.md) から各案を選べます。

[AGENTS.md](../AGENTS.md) を agent の入口にし、環境の準備、起動、設定の保存、検証、GitHub への変更の共有を日本語で案内する文書を追加しました。古い開発計画は歴史資料として分けています。

今回から `share/` には配布用のソース ZIP を置かず、このような更新ノートを残します。プログラムと説明を同じ Git リポジトリで共有します。

作品の動きや初期設定はそのままです。配信用の画面に UTF-8 の指定を補い、一般的な静的サーバーで色票名などが文字化けする問題も修正しました。

## なぜ変えたか

最終的にどの方向を採用するかはまだ決まっていません。今の案を残しながら別の案を比較できるように、コード・依存関係・説明をプロトタイプごとに分けました。

また、技術的な準備は agent に任せて、見た目や使い心地の検討に集中できるようにするためです。更新ノートには変更の理由も残し、次に作業する人とその agent が意図を引き継げるようにします。

## 次に試してほしいこと

agent に [AGENTS.md](../AGENTS.md) から始めてもらってください。Git 更新と環境の確認後、今の案を開く時はルートから `prototypes/circles08/` に移動し、そこで依存関係の準備と起動を行います。

手の近くで試す場合は Digit、上半身と両手を映して試す場合は Kinetic を選び、手で物体を押した時の範囲や反応を見てください。気に入った設定を次回も使いたい場合は、agent に保存を依頼してください。操作パネルの値は再読み込みだけでは保持されません。
