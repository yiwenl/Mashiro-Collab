# 一緒に試すためのプロトタイプと作業ガイド

- 日付: 2026-10-10
- 対象: プロジェクト全体、circles08

## 今回用意したもの

作品の方向を一緒に探るために、手や身体の動きで遊べるプロトタイプを用意しました。最終的にどの方向を採用するかは、まだ決まっていません。

最初の案は `prototypes/circles08/` にあります。球・箱・細長い棒が重なって色や模様をつくり、カメラで捉えた手の動きで物体を押せます。今後は別の案も個別のフォルダーに追加し、比べながら試せる構成です。[README](../README.md) に各案の一覧があります。

[README](../README.md) の本文や URL を、自分の PC を操作できる AI agent に渡すと、プロジェクトの取得、Node.js / npm の準備、依存関係のインストール、起動まで進めるための指示が揃っています。agent は続けて [AGENTS.md](../AGENTS.md) などのガイドを読み、設定の保存、動作確認、GitHub での変更の共有にも対応します。

`share/` には、このような説明や、今後の更新内容とその理由を残します。プログラムと説明を同じ Git リポジトリで共有します。

## こうした形にした理由

一つの案を完成形として決める前に、いくつかの表現や操作感を実際に試して比べたいと考えています。そのため、各プロトタイプを独立して動かせるようにしています。

技術的な準備は agent に手伝ってもらい、見た目や使い心地の検討に集中できるようにするためのガイドです。説明には意図も残し、お互いの工夫を理解しながら作業できるようにします。

## まず試してほしいこと

使っている agent に [ルート README](https://github.com/yiwenl/Mashiro-Collab/blob/main/README.md) の本文または URL を渡してください。agent が circles08 を起動し、ブラウザーで開くか、クリックできる URL を伝えます。開いた後もサーバーは動かしたままにする手順です。本人のログインや PC の許可が必要な時だけ、agent の案内に従ってください。

手の近くで試す場合は Digit、上半身と両手を映して試す場合は Kinetic を選び、手で物体を押した時の範囲や反応を見てください。気に入った設定を次回も使いたい場合は、agent に保存を依頼してください。操作パネルの値は再読み込みだけでは保持されません。

## 確認済み・まだ分からないこと

共有の準備時に、macOS / Node.js 22.17.0 で、新しい作業フォルダーへのインストール、自動テスト 45 項目、配信用ファイルの作成、開発版と配信版のブラウザー表示を確認しています。

使ってもらう PC での動作、実際のカメラでの認識精度、投影環境での操作感は、これから確認したい点です。動きの範囲や押した時の反応など、試して感じたことを教えてください。
